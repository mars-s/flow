# Security Policy

## Supported Versions

Only the latest release of Flow receives security fixes. Updates ship
through the in-app updater and https://flow.sh.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/mars-s/flow/security/advisories/new
